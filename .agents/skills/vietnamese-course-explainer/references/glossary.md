# Thuật ngữ Anh - Việt

Chỉ đọc các mục liên quan trực tiếp đến bài học hiện tại.

| English term | Cách diễn giải tiếng Việt |
|---|---|
| AI Agent | Hệ thống AI có mục tiêu, có thể dùng công cụ, quan sát kết quả và lặp lại |
| Model | Bộ máy suy luận tạo ra quyết định hoặc nội dung |
| Harness | Bộ khung bao quanh model gồm rules, tools, sandbox, orchestration và quan sát |
| Vibe Coding | Xây phần mềm nhanh từ yêu cầu tự nhiên, thường kiểm chứng còn ít |
| Agentic Engineering | Phát triển với agent trong hệ thống có spec, test, eval và guardrail |
| Context | Thông tin model nhận được để đưa ra quyết định |
| Static Context | Thông tin luôn được nạp như vai trò và hard rules |
| Dynamic Context | Thông tin chỉ nạp khi nhiệm vụ cần |
| Tool | Chức năng có schema mà agent được phép gọi |
| API | Giao diện hoặc hợp đồng trao đổi giữa các phần mềm |
| MCP | Giao thức chuẩn hóa cách agent khám phá và gọi công cụ |
| A2A | Giao thức cộng tác và giao việc giữa các agent |
| Agent Skill | Gói quy trình chuyên môn được nạp theo nhu cầu |
| Progressive Disclosure | Chỉ mở dần metadata, instructions và resources khi cần |
| Guardrail | Hàng rào kiểm soát hành vi hoặc đầu ra |
| Policy | Quy tắc được hệ thống kiểm tra và thực thi |
| Sandbox | Môi trường cô lập để giới hạn thiệt hại khi chạy code |
| Evaluation | Đánh giá chất lượng hành vi không chỉ bằng đúng/sai xác định |
| Trajectory | Chuỗi bước và tool calls agent đã thực hiện |
| Observability | Khả năng theo dõi logs, traces, chi phí và hành vi agent |
| BDD | Đặc tả hành vi bằng các scenario quan sát được |
| Given / When / Then | Hoàn cảnh ban đầu / hành động / kết quả bắt buộc |
